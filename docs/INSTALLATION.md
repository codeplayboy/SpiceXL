# Install SpiceXL

Download the matching file from the [SpiceXL v1.0.0 release](https://github.com/codeplayboy/SpiceXL/releases/tag/v1.0.0). Keep the installer from the release page; do not download similarly named files from third-party mirrors.

## Windows

1. Download **`SpiceXL-Windows-Setup-v1.0.0.exe`**.
2. Open the downloaded file. If Windows SmartScreen appears because this installer is not code-signed, verify that the filename matches the release, then choose **More info → Run anyway** if you trust this download.
3. In the setup wizard, choose **Only for me / current user** if the install-scope page appears. Do not choose an all-users option. You can choose an install folder, then select **Install**.
4. Start SpiceXL from the **SpiceXL** desktop shortcut or the Start menu.

Setup creates a desktop shortcut and a Start-menu shortcut. To remove the app, open **Settings → Apps → Installed apps → SpiceXL → Uninstall**, or use the SpiceXL uninstall shortcut in the Start menu. The installer build includes an uninstaller.

If Windows requests administrator access or offers only an all-users installation, cancel and contact the project maintainer rather than proceeding with a scope you did not intend.

## Android

1. Download **`SpiceXL-Android-v1.0.0.apk`** on your Android device.
2. Open the APK from Downloads and review Android’s install prompt.
3. If Android asks, allow your browser or file manager to install apps from this source, then return to the installer and tap **Install**.
4. Open SpiceXL from the app drawer.

Android may show an external-source or Play Protect warning because this APK is installed directly rather than through Google Play. Install only if you trust the source and the release file.

## Troubleshooting

- **The download will not open:** confirm the download completed and that you chose the installer for your device.
- **Windows blocks setup:** confirm the file came from the official release link above. Do not bypass a warning for an unverified copy.
- **A title does not play:** availability can depend on the selected title, source, network, and region; retrying cannot guarantee that every source is available.
